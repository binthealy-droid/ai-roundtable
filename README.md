# طاولة النقاش

موقع تطرح فيه موضوع (مع صور أو PDF)، فيشوفه **Claude وChatGPT وGemini وManus** بنفس اللحظة، ويتناقشون جولتين أو ثلاث تلقائياً، وبعدها Claude يكتب الخلاصة مبنية على النقاش ومنسوبة لكل واحد.

## كيف يشتغل

- الواجهة (`docs/`) تنسّق النقاش من المتصفح: ترسل لكل نموذج طلب مستقل، وتعرض كل رد أول ما يوصل.
- دوال Vercel (`api/`) وسيط يحمل المفاتيح ويكلم الـ API الرسمي لكل نموذج. المفاتيح ما تنكتب في GitHub أبداً.
- القاعدة (Neon عبر Vercel) تحفظ المواضيع والردود والخلاصات.
- Manus شغله غير متزامن: ننشئ مهمة وننتظرها. بعد ما يخلّص الثلاثة الباقين ننتظر Manus مدة قصيرة (الافتراضي 60 ثانية)، وإذا تأخر تكمل الجولة بدونه وردّه يظهر لما يوصل.

## خطوات النشر

1. **GitHub:** أنشئ مستودع جديد وارفع محتوى هذا المجلد كله.
2. **Vercel:** Add New → Project → اختر المستودع → Deploy (اترك الإعدادات كما هي).
3. **القاعدة:** من مشروعك في Vercel → تبويب **Storage** → Create Database → **Neon** → Connect to Project. يضيف `DATABASE_URL` تلقائياً، والجداول تنشأ لحالها أول ما تفتح الموقع.
4. **المتغيرات:** Settings → Environment Variables، وأضف:

   | الاسم | الوصف |
   |---|---|
   | `APP_PASSWORD` | كلمة سر الموقع (اختر وحدة طويلة) |
   | `ANTHROPIC_API_KEY` | مفتاح Claude |
   | `OPENAI_API_KEY` | مفتاح ChatGPT |
   | `GEMINI_API_KEY` | مفتاح Gemini |
   | `MANUS_API_KEY` | مفتاح Manus |

   بعدها اعمل **Redeploy** عشان تنقرأ.
5. افتح رابط Vercel (مثل `https://اسم-المشروع.vercel.app`). الواجهة تنخدم من نفس المشروع، فيشتغل مباشرة.

### لو تبي الواجهة على GitHub Pages

1. في GitHub: Settings → Pages → Branch: `main` والمجلد `/docs`.
2. عدّل `docs/config.js` وحط رابط Vercel في `API_BASE`.
3. في Vercel أضف `ALLOWED_ORIGIN` = `https://USERNAME.github.io` (بدون `/` في الآخر) ثم Redeploy.

## متغيرات اختيارية

| الاسم | الافتراضي | ملاحظة |
|---|---|---|
| `CLAUDE_MODEL` | `claude-sonnet-5-5` | تقدر تحط `claude-opus-5-5` لجودة أعلى |
| `OPENAI_MODEL` | `gpt-5` | حط اسم النموذج اللي تبيه من حسابك |
| `GEMINI_MODEL` | `gemini-flash-latest` | الطبقة المجانية ما تشمل نماذج Pro، حط `gemini-pro-latest` لو حسابك مدفوع |
| `OPENAI_REASONING_EFFORT` | (فاضي) | لو ChatGPT يتأخر ويطلع Timeout حط `low` (لنماذج التفكير فقط) |
| `MANUS_PROFILE` | `standard` | `lite` أسرع وأرخص، `max` أعمق وأبطأ |

## حدود لازم تعرفها

- **المرفقات:** المجموع 2.8 م.ب تقريباً (حد Vercel للطلب 4.5 م.ب والملفات تكبر لما تتحول base64). الصور تنصغّر تلقائياً. الملفات تنرسل للنماذج في كل جولة، لكن ما تنحفظ في القاعدة، يتحفظ بس أسماؤها.
- **مهلة الدالة:** 60 ثانية لكل طلب (أقصى حد في Vercel المجاني بدون Fluid Compute). لو تفعّلت Fluid Compute في مشروعك تقدر ترفعها في `vercel.json`.
- **التكلفة:** كل موضوع = عدد الجولات × 4 طلبات + طلب للخلاصة. جولتين = 9 طلبات. كل واحد يتحاسب من حسابه.
- **Manus:** الـ API يسمح بـ 10 مهام جديدة في الدقيقة، وكل مهمة تستهلك رصيد من حسابك. اشتراك Manus العادي غير مفتاح الـ API، وحساب Manus المجاني ممكن ينزّل المهام لـ `lite`.
- **الأمان:** الموقع محمي بكلمة سر واحدة. أي أحد يعرفها يصرف من مفاتيحك، فلا تشاركها.

## الملفات

```
api/ask.js        Claude + ChatGPT + Gemini
api/manus.js      إنشاء مهمة Manus ومتابعتها
api/history.js    حفظ وقراءة المواضيع
lib/common.js     كلمة السر، CORS، الاتصال بالقاعدة
docs/             الواجهة (index.html, app.js, style.css, config.js)
vercel.json       مهلة الدوال ومجلد الواجهة
```
